## 💻 What the Portfolio Is
**Olabode OS** (by Samuel Olabode) is a premium, personal product operating system and living proof showroom designed for clients and stakeholders looking to build launch-ready digital products. It models a responsive retro-futuristic terminal UI desktop showing verified live web applications, interactive visual mockups, and operational capability matrices.

---

## ⚡ Key Showroom Features
1. **Interactive Boot Screen Interface**: Retro-themed compilation logs displaying system settings and startup procedures with a fast-access `[ SKIP_BOOT.EXE ]` bypass button.
2. **Cockpit Multi-Theme Switcher**: Real-time theme injection supporting 4 premium custom-curated color directions:
   - **Cyberpunk Cyan (Default)**: Bright neon cyan grids with purple shadows.
   - **Luxury Gold**: Matte obsidian theme with glowing amber borders and luxury chips.
   - **Matrix Green**: Classic high-contrast dark green terminal aesthetics.
   - **Stealth Mono**: Minimalist, clean grayscale typography and white borders.
3. **Live Product Proof Blueprints**: 6 visual product mockup cards representing real software capabilities:
   - **Mama Guard**: Maternal vital status monitor (Active Live Beta link).
   - **Proof**: Gamified customer onboarding timeline tracking (Active Live Beta link).
   - **PredChain**: Web3 staking dashboard and wallet interface (Active Git Repository link).
   - **Chikini Monie**: Food ordering and operational tickets manager (Staging).
   - **Aristo Afrikana**: Seating map reservation manager (Staging).
   - **Bethel Portal**: Community media player streaming console (Staging).
4. **Mouse-Perspective Parallax Engine**: GPU-accelerated perspective tilts on the hero profiles and window cards that track cursor movement dynamically.
5. **Interactive CLI Terminal**: Functional input command field supporting directory commands (`help`, `clear`, `details <project_key>`, `skills`, `workflow`).
6. **Communications Uplink Form**: Integrated contact form simulating local compilation sequences, exposing automated mail client triggers and dynamic clipboard fallback mechanisms.

- **Boot Sequence & Bypass**: Successfully waits for skip clicks and fades in the main OS interface smoothly.
- **Theme Accents Switcher**: Clicking theme switcher buttons updates variables locally and persists theme choices in localStorage.
- **Spec Slide-Out Drawer**: Dynamic specifications rendering; opens via buttons or `details` CLI command and transitions smoothly with hardware-accelerated transforms. Close buttons, escape keys, and overlay backdrops successfully shut the drawer and trigger standard display-toggle reflow layouts.

## ⚠️ Known Limitations
- **No Global Git Binary**: Git is not globally registered in the local shell environment path on the current QA execution runner (commits and updates must be executed via Git-enabled IDE interfaces or administrative shells).
- **Staging Mockups**: Projects like Chikini Monie, Aristo Afrikana, and Bethel Portal are proposal directions and use deactivated action headers (`[ OFFLINE_STAGING.EXE ]`) to remain fully honest about readiness.
